Organização financeira com tecnologia

O Assistente Financeiro é um projeto educacional para ajudar a organizar informações básicas sobre finanças pessoais. A proposta é reunir ferramentas de análise e planejamento em uma interface simples, para que a pessoa compreenda melhor os dados que informa e explore possíveis próximos passos.

O projeto começou como um programa de console em C e evoluiu para uma aplicação web com Python e FastAPI. A integração com o Gemini acrescenta um chat para perguntas financeiras gerais.

O que a aplicação oferece

  • Análise de renda, gastos, dívidas, saldo e percentual de gastos.
  • Histórico das análises realizadas.
  • Estimativas para metas, reserva de emergência e economia potencial.
  • Simulação de quitação de dívida e resumo de despesas.
  • Respostas gerais sobre finanças com apoio de inteligência artificial.

Um projeto de aprendizado

Além de apoiar a organização financeira, o projeto serve para praticar desenvolvimento de APIs, validação de dados, testes automatizados, integração entre frontend e backend e uso responsável de serviços de inteligência artificial.

Os resultados são estimativas educativas e não substituem aconselhamento financeiro profissional.
